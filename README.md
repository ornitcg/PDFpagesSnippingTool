# PDF Pages Snipping Tool

כלי לחיתוך עמודים מקובץ PDF: בוחרים קובץ PDF וטווח עמודים, ומקבלים קובץ PDF חדש שמכיל רק את העמודים שנבחרו.

אפשר להפעיל את הכלי דרך חלון גרפי או משורת הפקודה.

## דרישות מוקדמות

- **Python 3.10 ומעלה.** אפשר להוריד מ-[python.org](https://www.python.org/downloads/). בהתקנה ב-Windows יש לסמן את האפשרות **"Add Python to PATH"**.

לבדיקה שפייתון מותקן, פותחים טרמינל ומריצים:

```
python --version
```

## התקנה

1. מורידים את הפרויקט:

   ```
   git clone https://github.com/ornitcg/PDFpagesSnippingTool.git
   cd PDFpagesSnippingTool
   ```

   (או מורידים כ-ZIP מ-GitHub דרך **Code → Download ZIP**, מחלצים, ופותחים טרמינל בתיקייה.)

2. מתקינים את הספרייה הנדרשת (פעם אחת בלבד):

   ```
   pip install -r requirements.txt
   ```

## הפעלה עם ממשק גרפי

```
python pdf_snip_gui.py
```

ייפתח חלון. השלבים:

1. לוחצים על **"בחר קובץ..."** ובוחרים קובץ PDF. יוצג מספר העמודים בקובץ.
2. מקלידים **טווח עמודים** (ראו פורמט בהמשך).
3. **קובץ פלט** הוא אופציונלי. לוחצים על **"שמור בשם..."** כדי לבחור שם ומיקום. אם משאירים ריק, הקובץ נשמר ליד הקובץ המקורי.
4. לוחצים על **"צור PDF"**.

## הפעלה משורת הפקודה

```
python pdf_snip.py <קובץ-PDF> <טווח-עמודים> [-o <קובץ-פלט>]
```

דוגמאות:

```
python pdf_snip.py report.pdf 3-7
python pdf_snip.py report.pdf 1,3,5-8
python pdf_snip.py "C:\My Files\report.pdf" 2-4 -o summary.pdf
```

> אם נתיב הקובץ מכיל רווחים, יש לעטוף אותו במירכאות.

הרצה של `python pdf_snip.py` בלי ארגומנטים פותחת את הממשק הגרפי.

## פורמט טווח העמודים

מספור העמודים מתחיל מ-1.

| מה מקלידים | אילו עמודים יופיעו בקובץ החדש |
|---|---|
| `5` | עמוד 5 בלבד |
| `3-7` | עמודים 3 עד 7 (כולל) |
| `1,3,5-8` | עמודים 1, 3, 5, 6, 7, 8 |
| `8-` | מעמוד 8 ועד סוף הקובץ |
| `-3` | מתחילת הקובץ ועד עמוד 3 |

## שם קובץ הפלט

אם לא בוחרים קובץ פלט, הקובץ החדש נשמר באותה תיקייה של הקובץ המקורי, ובתחילת שמו מופיע טווח העמודים:

| קובץ מקורי | טווח | קובץ פלט |
|---|---|---|
| `report.pdf` | `3-7` | `3-7_report.pdf` |
| `report.pdf` | `1,8-10` | `1_8-10_report.pdf` |

## הודעות שגיאה

הכלי מציג הודעת שגיאה ולא יוצר קובץ במקרים הבאים:

- הקובץ לא קיים.
- הקובץ אינו PDF. הבדיקה כוללת גם את הסיומת וגם את תוכן הקובץ, כך שקובץ אחר ששמו שונה ל-`.pdf` יזוהה.
- הקובץ מוגן בסיסמה.
- טווח העמודים לא תקין, הפוך (למשל `7-3`), או חורג ממספר העמודים בקובץ.
